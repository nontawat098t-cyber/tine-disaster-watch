# TINE DISASTER WATCH — Starter Website

เว็บต้นแบบภาษาไทยสำหรับติดตามสภาพอากาศและเตรียมพร้อมรับมือภัยพิบัติ ออกแบบให้รองรับมือถือและคอมพิวเตอร์

## สิ่งที่ทำได้ในเวอร์ชันนี้
- แผนที่ออนไลน์จาก OpenStreetMap ผ่าน Leaflet
- เลือกพื้นที่ตัวอย่างในประเทศไทย
- ดึงข้อมูลอุณหภูมิ ความชื้น ปริมาณฝน ลม และพยากรณ์รายชั่วโมงจาก Open-Meteo โดยไม่ต้องใช้ API key
- กราฟฝนรายชั่วโมงจากข้อมูลพยากรณ์
- เช็กลิสต์เตรียมพร้อมน้ำท่วม
- ระบุชัดเจนว่ายังไม่ได้เชื่อมเรดาร์ฝน เส้นทางพายุ และสถานีวัดระดับน้ำจริง

## เปิดดูบนคอมพิวเตอร์
1. ดาวน์โหลดและแตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `tine-disaster-watch` ใน Visual Studio Code หรือโปรแกรมแก้ไขข้อความ
3. เปิด `index.html` ในเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code
4. ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดแผนที่และข้อมูลพยากรณ์

## เผยแพร่ฟรีด้วย GitHub Pages
1. สร้างบัญชี GitHub ที่ https://github.com/
2. สร้าง repository ใหม่ เช่น `tine-disaster-watch`
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปไว้ที่ root ของ repository
4. ไปที่ **Settings → Pages**
5. ในส่วน Build and deployment เลือก **Deploy from a branch** เลือก branch `main` และ folder `/ (root)` แล้วกด Save
6. รอให้ GitHub Pages เผยแพร่ แล้วเปิด URL ที่แสดงในหน้า Pages

ชื่อเมนูอาจเปลี่ยนเล็กน้อยตามหน้าตา GitHub ในขณะนั้น การเผยแพร่ด้วย Pages ฟรีสำหรับ repository สาธารณะตามเงื่อนไขของ GitHub

## ข้อจำกัดสำคัญ
- ข้อมูลจาก Open-Meteo เป็นข้อมูลพยากรณ์จากแบบจำลอง ไม่ใช่เรดาร์ฝนสดหรือประกาศเตือนภัยทางการ
- แผนที่เป็นแผนที่พื้นหลัง ไม่ใช่ชั้นข้อมูลฝน
- ระบบติดตามพายุ เส้นทางพายุ ระดับน้ำท่วม ศูนย์พักพิง และการแจ้งเตือนภัยอัตโนมัติยังไม่ได้เชื่อมต่อ
- เช็กเงื่อนไขการใช้งานและข้อจำกัดปัจจุบันของ Open-Meteo, OpenStreetMap, Leaflet และ GitHub ก่อนเปิดใช้ในวงกว้าง
- ห้ามใช้เว็บไซต์เวอร์ชันนี้แทนประกาศเตือนภัยหรือคำแนะนำจากหน่วยงานทางการ
