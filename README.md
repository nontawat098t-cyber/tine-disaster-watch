# TINE DISASTER WATCH — V2
เวอร์ชันปรับหน้าเว็บเป็น Dashboard แผนที่ประเทศไทย

หมายเหตุ: ชั้น “ฝนตัวอย่าง” และ “พื้นที่เฝ้าระวังตัวอย่าง” ยังไม่ใช่ข้อมูลเรดาร์หรือคำเตือนภัยจริง
